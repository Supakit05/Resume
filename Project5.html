AREX Platform

Internship Botnoi Academy Web Platform Frontend Dev UI/UX

Overview

โปรเจกต์นี้เป็นการพัฒนาแพลตฟอร์ม AREX (arex-platform) ในระหว่างการฝึกงานชั้นปีที่ 2 เทอม 3 ณ Botnoi Academy โดยมีส่วนร่วมในการพัฒนา Web Platform และปรับปรุง User Experience / User Interface เพื่อรองรับการทำงานของระบบและการใช้งานของผู้ใช้ให้มีประสิทธิภาพสูงสุด

Challenge

  • พัฒนา Web Platform ให้ตอบสนองรวดเร็วและรองรับการเชื่อมต่อกับระบบ API
  • ออกแบบและปรับปรุง UI/UX ให้ใช้งานง่าย จัดการข้อมูลและฟังก์ชันที่ซับซ้อนได้อย่างชัดเจน
  • ทำงานร่วมกับทีมผู้พัฒนาผ่านระบบ Git/GitHub ตามมาตรฐานการทำงานระดับองค์กร

Solution

มีส่วนร่วมในการพัฒนาระบบใน 3 ส่วนหลัก:

Platform Development

ร่วมพัฒนาหน้าเว็บและคอมโพเนนต์ของแพลตฟอร์มให้ทำงานลื่นไหล รองรับ Responsive Design

UI/UX Enhancement

ออกแบบและปรับปรุง Interface ให้มีความทันสมัย ใช้งานสะดวก และลดขั้นตอนที่ซับซ้อน

API Integration

เชื่อมต่อข้อมูลระหว่าง Frontend และ Backend API อย่างถูกต้องและปลอดภัย

Key Responsibilities & Process

1. Requirements & System Analysis

ทำความเข้าใจ Requirement และโครงสร้างของระบบ AREX Platform ร่วมกับทีมและพี่เลี้ยงฝึกงาน

2. Frontend & UI Implementation

พัฒนาหน้าตาและฟังก์ชันการใช้งานของแพลตฟอร์มตามโจทย์ที่ได้รับมอบหมาย

3. API Integration & Testing

เชื่อมต่อและทดสอบการรับส่งข้อมูลระหว่างหน้าเว็บกับ API ด้วย Postman และเครื่องมือทดสอบ

4. Team Collaboration & Git Workflow

ส่งต่องานผ่าน GitHub มีการสร้าง Pull Request, Code Review และเข้าร่วมการประชุมทีมอย่างสม่ำเสมอ

Tools & Technologies
