PROJECT 004

Apartment Management System

Full-Stack TypeScript Java Docker

ระบบจัดการหอพัก Full-Stack ครบวงจร พัฒนาด้วย TypeScript และ Java พร้อม Docker สำหรับการ Deploy

Scroll to explore

Overview

โปรเจกต์ Apartment Management System เป็นระบบจัดการหอพักแบบ Full-Stack ที่ออกแบบมาเพื่อช่วยในการบริหารจัดการห้องพัก ผู้เช่า การชำระเงิน และการแจ้งซ่อมอย่างมีประสิทธิภาพ พัฒนาเป็นโปรเจกต์วิชาเรียนด้วยเทคโนโลยีที่ทันสมัย

Challenge

  • ออกแบบระบบจัดการหอพักที่ครอบคลุมทั้ง Frontend และ Backend
  • จัดการฐานข้อมูลห้องพัก ผู้เช่า และรายการชำระเงินอย่างเป็นระบบ
  • สร้างระบบที่สามารถ Deploy ด้วย Docker ได้อย่างสะดวก

Solution

พัฒนาระบบแบ่งเป็น 3 ส่วนหลัก:

Frontend

พัฒนาหน้าเว็บด้วย TypeScript สร้าง UI ที่ใช้งานง่ายสำหรับผู้จัดการหอพักและผู้เช่า

Backend API

สร้าง REST API ด้วย Java สำหรับจัดการข้อมูลห้องพัก ผู้เช่า และการชำระเงิน

Deployment

ใช้ Docker containerize ทั้งระบบ ให้สามารถ Deploy ได้ง่ายและรวดเร็ว

Tech Stack

Frontend — TypeScript

ใช้ TypeScript เป็นภาษาหลักในการพัฒนาส่วน Frontend พร้อม HTML และ CSS สำหรับ UI

Backend — Java

ใช้ Java สำหรับสร้าง Backend API และ Business Logic ของระบบจัดการหอพัก

DevOps — Docker

ใช้ Dockerfile สำหรับ containerize แอปพลิเคชัน ทำให้ Deploy และจัดการได้สะดวก

Tools Used

TypeScript Java HTML CSS JavaScript Docker VS Code
